# UniFi Toolkit

[Crosstalk-Solutions/unifi-toolkit](https://github.com/Crosstalk-Solutions/unifi-toolkit) als Home-Assistant-App:
Dashboard, Wi-Fi Stalker, Threat Watch, Network Pulse und House Arrest für UniFi-OS-Konsolen.

Läuft über Ingress in der HA-Seitenleiste, die Anmeldung übernimmt Home Assistant.
